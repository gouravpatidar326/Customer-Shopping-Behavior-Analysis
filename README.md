# 🛍️ Customer Shopping Behavior Analysis

An end-to-end data analytics project that explores consumer purchasing patterns, demographic trends, and subscription behavior. This project demonstrates a full data pipeline: from raw data processing in **Python** to advanced business querying in **SQL** and interactive visualization in **Power BI**.

## 🚀 Project Overview
The goal of this analysis is to help a retail business understand its primary revenue drivers. By analyzing 3,900+ transactions, we identify high-value customer segments, the impact of discounts on purchasing volume, and the correlation between customer loyalty and subscription status.

## 📂 Repository Structure
* **`Data/`**: Contains the raw dataset (`customer_shopping_behavior.csv`) and the processed SQL-ready data.
* **`Notebooks/`**: Jupyter Notebook containing Exploratory Data Analysis (EDA), data cleaning, and feature engineering.
* **`SQL/`**: Database scripts including complex queries for revenue analysis, window functions, and customer segmentation.
* **`Dashboard/`**: The interactive Power BI (`.pbix`) file for visual exploration.
* **`Presentation/`**: A comprehensive **Project Report (PDF)** and **PPT** summarizing the findings for stakeholders.

## 🛠️ Tech Stack & Tools
* **Data Processing:** Python (Pandas, NumPy)
* **Exploratory Data Analysis:** Matplotlib, Seaborn
* **Database Management:** MySQL (Joins, CTEs, Window Functions)
* **Data Visualization:** Power BI
* **Reporting:** Microsoft PowerPoint

## 📈 Key Insights
* **Customer Retention:** Over **80%** of the revenue is generated by "Loyal" customers (those with >10 previous purchases).
* **Demographic Split:** Male customers account for **68%** of total revenue, indicating a significant growth opportunity in the female segment.
* **Subscription Opportunity:** While loyalty is high, only **27%** of customers are currently subscribed, suggesting a gap that can be closed with targeted loyalty programs.
* **Top Categories:** **Clothing** and **Accessories** are the leading categories, contributing over **$178,000** in total sales.
